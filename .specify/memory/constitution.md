# vue-app Constitution

## Core Principles

### I. Application Vue
L'application doit être développée en utilisant le framework Vue 3. L'utilisation de la Composition API avec `<script setup>` est obligatoire pour tous les nouveaux composants afin de garantir une cohérence et une performance optimales.

### II. TP Projet Scolaire
Le projet s'inscrit dans un cadre pédagogique (TP). Le code doit être clair, commenté et respecter les consignes académiques fournies. L'accent doit être mis sur la compréhension des concepts web et la propreté de l'implémentation.

### III. Implémentation App Web en Vue
L'architecture de l'application doit suivre les standards Vue (SFC). Les composants doivent être modulaires et réutilisables. La gestion de l'état et du routage doit utiliser les bibliothèques officielles recommandées par l'écosystème Vue.

## Contraintes Additionnelles
L'application doit être responsive et accessible. L'utilisation de TypeScript est requise pour assurer la sécurité du typage et faciliter la maintenance.

## Processus de Développement
Chaque nouvelle fonctionnalité doit être spécifiée avant son implémentation. Le code doit passer une vérification de linting avant d'être intégré.

## Governance
La Constitution prévaut sur toutes les autres pratiques de développement. Toute modification de la gouvernance ou des principes doit faire l'objet d'une mise à jour documentée de ce fichier.
